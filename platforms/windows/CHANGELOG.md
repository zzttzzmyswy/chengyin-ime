# 发行说明

## 0.1.0-preview13 · 2026-10-05

- 修复模糊音与纠错时无依据的单字拼接；完整短词不通过缩写组句制造伪词。
- 整词和单字独立匹配、排序，准确历史和模糊历史分别最多两项；整词不混入前缀单字。
- 模糊与纠错候选优先少改动匹配，较远的高频词不挤占较近词条；补齐音节末尾漏键。
- 保留标准读音逐字母标记、默认关闭的拼音显示、空格提交原始输入与实时外观同步。

## 0.1.0-preview12 · 2026-10-05

- 设置通知补充后台文件变更兜底；通知映射不可用时仍可同步，不在按键线程读取配置。
- 已显示的候选主题、字号、排列、间距和拼音显示直接重绘，不依赖宿主编辑锁，不改变正在输入的正文。
- 候选页增加明确的“显示候选框拼音（默认关闭）”开关；关闭包括原始/纠错拼音，开启保留逐字母标记。
- 旧配置首次读取也默认关闭，通过新字段保存明确开启的选择；词库/匹配规则仍在下一段输入生效。

## 0.1.0-preview11 · 2026-10-05

- “常见键盘失误”明确说明四类规则适用于词库拼音，每项标注“示例”，使用不同拼音展示。
- 扩展既有回归覆盖 hao、ping、shi、ni'hao 的匹配、逐字母标记与提交，验证规则不限定 zhang；算法范围不变。

## 0.1.0-preview10 · 2026-10-05

- 按用户要求删除 Deepseek 大肥鱼、初音未来、洛天依三个主题及其插画、配色、装饰区。
- 保留主题设置页、候选预览和 Windows 系统/白/黑主题；后续主题设计等待用户确定。
- 旧配置中已选中的角色主题回退为系统主题，保留字号、布局、词库和其他选项；读取时不改写配置文件。
- 保留既有候选布局、输入逻辑和 Shift 修正。
- 新增“模糊音”页：11 组双向声母/韵母匹配和相邻字母交换、漏字母、QWERTY 相邻键、重复按键四项独立开关，默认关闭。
- 标准拼音中仅匹配/修正位置加粗并使用强调色；普通字母、补全后缀和分隔符不标记。纠错候选在可内嵌编辑的宿主中仍显示标准拼音供辨认。
- 正确整词与整句优先，保留原始拼音、光标、翻页和分段选词；空格仍提交原始拼音。

## 0.1.0-preview9 · 2026-10-05

- 主题美化整个候选框：原创矢量插画、渐变背景、圆角边框、纹样、候选选中态和序号徽章。
- Deepseek 大肥鱼：胖鲸、海浪与气泡；初音未来：双马尾头像、耳机、音符与电子舞台；洛天依：灰发绿眼头像、云纹与飘带。

- 避免传统 IMM/TSF 宿主仅测试按键时误拦截空闲 Shift 组合；组合键不会切换中英文。
- 保留 preview8 的十一项改进。角色插画为本项目原创代码，无第三方图片依赖。
