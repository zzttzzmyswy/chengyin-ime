# 发行说明

## 0.1.0-preview19 · 2026-10-05

- 回归保护 `paizhao/pai'zhao`：“拍照、牌照”优先，无词库依据的“拍找、派找、排找”等不参与组词。
- 未收录组合的历史提权要求至少三次近期命中，旧学习格式的累计次数不再直接作为质量依据；词库内的旧习惯继续可用。
- 保留学习条目，近期证据不足只取消提权；仍支持重复选择未登录词，低命中遗忘沿用既有规则。
- 注意：设置热更新不等于二进制热替换，升级后已加载旧 DLL 的应用须重新打开才能使用新算法。

## 0.1.0-preview18 · 2026-10-05

- 修复显式组合声母被当作更多字缩写，以及未分隔词库拼音的词长解析。
- 首字母索引支持零声母 a/e/o，完整全拼仍保留原匹配路径。
- 修复尾部分隔符令整词候选消失、学习键无法保存的问题。
- 按规范文件路径隔离学习清空/导入代际，保留其他文件的待保存事件。
- 自动检查的配置发布与消费使用进程专属测试通道，避免刷新个人应用会话。
- 更新器严格验证 release 标签、安装包名称、下载地址与 JSON 字段类型。
- 完成项目审查并建立按风险与验收门槛推进的后续修复计划。

## 0.1.0-preview17 · 2026-10-05

- 完整声母缩写优先匹配一字一个首字母的词库整词；例如 `ssdd` →“世世代代”。
- 存在同字数完整词条时，较少字、模糊音或键盘纠错候选不抢先；没有才使用原回退策略。
- 独立共享缩写索引避免有界搜索提前裁掉低频词，保留完整同音分页和最多两项准确历史提权。
- 正常缩写的展开不标为错拼；全拼、真正的纠错字母标记及前缀上屏保持原行为。

## 0.1.0-preview16 · 2026-10-05

- 保留整词/整句匹配，额外提供从剩余拼音开头截取的词组和单字，前缀同音词支持完整分页。
- 选择前缀立即上屏，未选拼音重新匹配；取消、退格和光标编辑只影响剩余部分。
- Windows TSF 同步缩短编辑范围，数字、鼠标及宿主候选使用相同路径；空格仍提交剩余原始拼音。
- 学习仅在宿主成功接受后记录所选部分；C ABI 增加显式模式，旧适配器默认行为保持兼容。

## 0.1.0-preview15 · 2026-10-05

- 完整准确词条保护其输入范围，过滤拆词形成的同音组句。
- 长句加入跨词边界词库证据、离线搭配和有限代词框架；有完整可靠解析时过滤弱组合，模糊/纠错组句不走无依据边界。
- 未知学习组合至少选择三次才提权；词库已确认读音的词仍可一次学习，至少八次观测且平滑近期命中率低于 50% 时取消提权。
- 保留 8192 学习容量、动态缓存与原有遗忘机制；词库变化也使历史可信度缓存失效。

## 0.1.0-preview14 · 2026-10-05

- 学习数据上限扩至 8,192 项，备份字节上限同步扩至 4 MiB；支持读取旧学习文件。
- 增加每会话独立的动态历史查询缓存，按复用率调整活动容量；数据变化时失效。
- 按成功选词的近期命中率遗忘，统计随使用逐步衰减，容量满时优先淘汰低命中记录。
- 新版学习备份保存命中统计，保护频繁命中的词，取消、原文提交和失败写入不计学习。

## 0.1.0-preview13 · 2026-10-05

- 修复模糊音与纠错时无依据的单字拼接；完整短词不通过缩写组句制造伪词。
- 整词和单字独立匹配、排序，准确历史和模糊历史分别最多两项；整词不混入前缀单字。
- 模糊与纠错候选优先少改动匹配，较远的高频词不挤占较近词条；补齐音节末尾漏键。
- 保留标准读音逐字母标记、默认关闭的拼音显示、空格提交原始输入与实时外观同步。

## 0.1.0-preview12 · 2026-10-05

- 设置通知补充后台文件变更兜底；通知映射不可用时仍可同步，不在按键线程读取配置。
- 已显示的候选主题、字号、排列、间距和拼音显示直接重绘，不依赖宿主编辑锁，不改变正在输入的正文。
- 候选页增加明确的“显示候选框拼音（默认关闭）”开关；关闭包括原始/纠错拼音，开启保留逐字母标记。
- 旧配置首次读取也默认关闭，通过新字段保存明确开启的选择；词库/匹配规则仍在下一段输入生效。

## 0.1.0-preview11 · 2026-10-05

- “常见键盘失误”明确说明四类规则适用于词库拼音，每项标注“示例”，使用不同拼音展示。
