# 澄音输入法 · Windows x64 全拼

当前版本：0.1.0-preview7。使用原生 TSF 和共享 Rust 核心，目标 Windows 10
2004（build 19041）及更新版本、Windows 11，Intel/AMD x64。

本版增加配置自动同步、嵌入式输入测试、经典 Windows 设置与矩形候选框、
中/英语言栏按钮和跟随模式的中文标点。保留开源常用词库、搜狗导入、整句、
首拼/声母混输、联想、翻页、中间编辑和本地选词学习。

自动化覆盖核心、模拟 TSF、Wine 和安装生命周期。真实 Windows 11 任务栏
呈现、Notepad3 及其他应用的兼容性仍需实机验收，详见后文。

## 单文件安装与卸载

交付一个离线 EXE：`chengyin-windows-x64-0.1.0-preview7-gnu.exe`。
双击安装向导并接受 UAC；无需解压、PowerShell、Rust、额外运行库或联网下载。
安装后的 DLL、说明和卸载程序由安装器管理，单文件指交付的安装包。

安装后注销并重新登录，Win+Space 选择“澄音输入法（全拼预览）”。尚未添加中文
时先在系统语言设置中添加“中文（简体，中国）”。使用日常账号提升权限；
输入另一个管理员账号的凭据时，profile 启用属于那个账号。安装不改变默认输入法。

开始菜单提供设置、使用说明和卸载入口；输入测试位于设置的“输入测试”页；也可通过 Windows 的
“已安装的应用”卸载。程序不会自动注销或重启。升级时占用的旧 DLL 安排
下次重启删除，未知文件和 `%LocalAppData%\MyswyIME` 中的用户词库、设置和学习数据保留。

显示名称已改为“澄音输入法”；既有配置和安装目录继续沿用原内部标识，
从旧版本升级会保留数据并替换开始菜单名称。

安装在 `%ProgramFiles%\MyswyIME\版本`，校验完新文件才切换注册。
支持同版修复、升级失败恢复旧注册、preview1 ZIP 标准布局迁移；拒绝降级、
同版本不同内容、外来注册和重解析点安装目录。已有应用可能继续加载旧服务，
升级后注销或重启使其释放。当前 EXE 未签名，包内 BUILD_INFO.json 和
SHA256SUMS.txt 提供构建记录及完整性校验，不替代发布者签名。

## 输入操作

| 操作 | 行为 |
| --- | --- |
| 字母 / `'` | 全拼，可省略或显式分隔音节；`v` 表示 ü；Shift 字母转小写 |
| 首拼 / 混输 | `zg` → “这个 / 中国”等候选；`zhongg` / `zguo` / `zhg` → “中国”；支持 `zh/ch/sh` 声母及撇号分隔 |
| 连续首拼 | `wxhzw` → “我喜欢中文”；`jttqhh` → “今天天气很好” |
| 上屏联想 | 根据刚提交的中文提供后续词；Tab 或鼠标确认，上下/翻页导航；空格、数字、Enter 等直接交给应用；Esc 关闭 |
| 连续全拼 | 例如 `woxihuanzhongwen` → “我喜欢中文”；最后一个未完成音节可预测词尾 |
| 空格 / 数字 1–9 / 点击候选 | 选择当前页候选；选整句上屏，选前缀词后保留剩余拼音 |
| PgUp/PgDn 或 -/= | 前后翻页；候选窗底部也可点击翻页 |
| 上下键 | 改变当前页选中候选 |
| 左右 / Home / End | 在未选定的拼音中移动光标，不结束组合 |
| 退格 / Delete | 删除光标前 / 后一键；在已选片段边界退格可撤回该片段 |
| Esc / Enter | 取消整个组合 / 提交已选中文加剩余拼音原文 |
| 标点 | 中文模式默认转换为中文标点，如 ，。！？；支持成对引号、—— 和 ……；英文模式透传；可在设置关闭转换。拼音中的撇号仍是分隔符 |
| 左 Shift / Ctrl+Space | 切换中英文；Shift 只在单独释放时切换，组合键不切换；可改为左右 Shift 或禁用；激活时按设置选择默认模式 |
| Caps Lock / Tab / 其他 Ctrl/Alt/Win 快捷键 | 结束组合并透传给应用 |
| 换输入框 / 外部移动插入点 / 切换输入法 | 保留旧框显示文本，清除候选，新框独立开始 |

输入上限 63 字节，预编辑和提交上限 256 UTF-8 字节。默认 5 条/页，设置可选 5/7/9 条；
候选按需遍历；每次输入最多保留 4096 个候选，游标堆预算 1024 项。
整句每个输入位置保留 16 条路径，每个词节点使用前 16 个同音词。
达到显式预算时提示分段输入；不将工作预算耗尽伪装成词库已经没有后续条目。
整句使用离线词频及常用搭配排序。当前上下文与最近 32 次选词偏好只存在
内存；失焦、重置或切换词库会清除。首屏排序最多重排 64 条，联想最多 128 条。
完整全拼先解码，缩写备选按需展开；两组最多各 16 条句子，缩写词图最多
96 个活跃状态，整词查询最多 256 个。Windows 已有本地持久选词偏好；双拼继续后续开发。

候选窗不抢焦点，按插入点、屏幕工作区和 DPI 调整。宿主接管 UI 时通过
ITfCandidateListUIElementBehavior 读取、重新排版、选择、提交或取消当前核心页；
PgUp/PgDn 继续切换核心候选页。陈旧/重复提交在写锁中校验并丢弃。
定位依次尝试 TSF 光标、非空组合范围、当前线程 Win32 光标、同一输入框的
已有有效位置及当前输入视图。排版暂未就绪时继续更新当前候选窗，不反复隐藏；
明确被裁剪/失焦或没有安全位置时隐藏。宿主未向输入服务投递事件时，位置回退
不能解决激活问题。设置程序显式激活 TSF，嵌入测试框共用 TSF 消息循环处理按键。

## 设置与本地学习

设置采用六个原生选项卡：输入、候选、词库、学习、输入测试、关于。
使用标准按钮、下拉框、分组框与系统颜色；按实际文字高度布局，长页面可滚动。
候选框改为矩形边框与标准选中颜色，仍使用稳定窗口和双缓冲，输入时不反复创建窗口。

设置字体与候选字体独立。候选默认 Microsoft YaHei UI，缺失时回退到可用中文字体。
可调整候选字体、12–32 字号、系统/浅色/深色颜色、纵向/横向排列、紧凑/标准间距、
5/7/9 条候选、音节分隔和候选拼音；另有默认英文、Shift 范围、中文标点、联想、
学习与光标位置回退。默认模式只影响下一次服务激活，不覆盖正在使用的中/英状态。

“输入测试”包含标准 Edit、RichEdit 与密码框，不保存测试文字；切换设置页、缩放和
调整窗口大小时保留测试文字。旧独立输入测试程序及其开始菜单入口会在升级时移除。

自动分隔只改变候选框显示，不更改宿主原拼音和光标索引。手工输入 `'` 是
解码约束：例如 `xi'an` 明确要求“西安”，与 `xian` 的学习偏好分开保存。

学习只在宿主成功接受纯中文选词/整句后生效；输入取消、原文、混合英文、
标点提交及敏感字段不记录持久偏好。深页选过的同音词可进入首屏，按选择频次
排序，频次相同时近期选择优先。实际拼写（包含手工分隔）和选中文字构成一项，
最多 4,096 项，超限淘汰最旧项。文件有校验和与严格边界检查；损坏文件保留，
不静默覆盖。后台有界队列合并多个应用的选择，并原子保存；清除/导入会使
旧的排队写入失效。异常退出或队列满时，尚未保存的少量选择可能丢失。

点击“应用”、导入/恢复词库、导入/清除学习后，已激活的输入服务自动接收通知。
后台检查共享版本号（间隔 200 ms），有更新才读取文件，并回到应用的 TSF 线程发布。
外观与标点设置更新后生效；正在输入的拼音保留原词库和候选策略，结束后下一次输入
使用新配置，不需要重新打开应用。大型词库的加载时间另计。手工改 INI 不会发布通知。
当前应用的新选词立即影响自身排序；其他应用的普通选词同步仍在重新激活或配置更新时读取。
关闭学习停止记录与个性化排序，已有数据保留；提供
备份、校验后导入和清除（`.chengyinuser`，兼容旧 `.myswyuser`）。`preferences.ini` 与 `learning.profile` 位于
`%LocalAppData%\MyswyIME`，升级/卸载均保留；文件未加密，备份可能包含敏感词句。

## 词库与导入

内置 87,540 条字词：Rime pinyin-simp 的 65,125 条基础词（Apache-2.0），
以及从 jieba 筛选的 22,415 条常用词（MIT）。固定修订、原始许可证与转换
记录位于 RUNTIME_LICENSES.zip 的 vocabulary/；无需额外词库下载。
新增词只使用源词库里读音唯一的汉字，不猜多音字。独立语料首选率仍待评测。

设置提供“追加词库”“替换词库”和“恢复内置词库”。追加保留现有词条，首次
追加保留全部内置词库；重复拼音/文字项取最大频率。支持经典搜狗 `.scel`
0x44/0x45、搜狗文本导出（UTF-8 / UTF-16LE / GBK）、本项目 TSV 和二进制。
文本例：`'ni'hao 你好`，或 `ni'hao<TAB>你好<TAB>100`。读取二进制 v1/v2，
保存为 v2。规范词条拼音最多 255 字节，较长词条可用首拼；词库最多 64 MiB、
250,000 条。未知、加密或其他私有搜狗格式暂不支持；格式边界见源码中的
`docs/SOGOU_COMPATIBILITY.md`。

导入先校验，再写临时文件、刷盘和原子替换；无效文件或保存失败保留原设置。
成功后自动通知现有服务后台加载。活跃组合保留自己的只读词库快照，完成后
使用新词库；输入线程不逐键读取文件。首次激活仍读取初始配置与词库。
重新加载失败时保留可用快照；进程首次加载无效文件则回退内置词库。
词库存在 `%LocalAppData%\MyswyIME\dictionary.custom`，升级和卸载均保留。

密码、私密、PIN、禁用和只读上下文绕过中文输入，不用于联想或学习。当前
上下文和临时偏好不会写盘；持久学习仅保存上述选词偏好，不读取应用周边文本、不联网。
未提供 InputScope 的传统 Edit/RichEdit 密码框也检查密码样式。安全模式不激活服务。

## 集中实测清单

有时间时完成以下一次检查即可，不要求逐轮测试开发切片：

1. 安装、注销重登：Win+Space 中可见澄音；默认输入法没有被改变。
2. 设置的“输入测试”页或记事本：`woxihuanzhongwen` 空格；`shi` 翻页再数字选词；
   `nhao` Home、右、补 `i` 再空格；`wovvvv` 空格、Home、退格、Esc；
   `wxhzw` / `jttqhh` 空格；`nihao` 上屏后用 Tab 选择联想“世界”。
3. 在常用浏览器、聊天或编辑器、Terminal 中重复整句和翻页，切换两个输入框，
   确认不丢字、不重复上屏；密码框只输入英文；左 Shift 与 Ctrl+Space 可切换，
   Shift+字母/组合键不误切换；`xi'an` 空格应提交“西安”。
4. 检查常用缩放下候选跟随光标；如有本地搜狗词库，用设置追加导入一次，
   保持原应用打开，再查一个词，确认内置词仍可用；无效文件应保留原设置。
5. 在设置中调整候选字体、横向/纵向、主题及页数；反复选一个非首选同音词，
   换输入框后确认排序；备份/关闭/清除学习按预期生效。
6. 保持已有应用打开，在设置点击“应用”修改外观、页数与标点，完成当前拼音再观察下一次输入；轻按左 Shift 检查任务栏中/英与澄音标识。
7. 不再使用时通过系统应用列表卸载。

用户反馈：旧版输入测试程序与 Notepad3 无候选，ChatGPT 应用可正常触发。
本批已改进 TSF 激活、注册类别、输入模式和位置回退，并建立模拟回归；
真实 Windows 的 Notepad3 与标准控件仍未复测，不能据此宣称已兼容。

如有问题，记录系统/应用版本、操作序列和实际结果。构建诊断在安装目录
BUILD_INFO.json；`myswy_probe.exe 绝对路径\myswy_tsf.dll --registered` 只读检查
导出、COM 和注册，不收集输入历史。

## 自动化及开发

Wine 10 + Xvfb 的六个 CTest 覆盖原子词库导入、按键/UTF-16/候选窗、COM、
模拟 TSF 写锁和宿主故障、整句/首拼/混输/编辑、Tab 与宿主联想选择、GBK/SCEL
追加、失败恢复、隐私作用域、宿主 UI 选择和取消、
陈旧回调、延迟自身编辑通知、临时 NOLAYOUT、左 Shift、手工分隔、
六页原生设置/文字与控件不重叠/DPI/滚动/嵌入测试框保留、并发学习与清除后不复活、损坏恢复、稳定绘制资源及
100 次激活/输入/停用；新增多个已激活应用的配置通知、连续保存合并、
损坏更新保留、更新期间输入快照、标点提交失败及语言栏 COM 生命周期。模拟 TSF 使用相同生产代码的测试 DLL，
隔离用户词库、设置与学习写盘，防止依赖开发者设置；该 DLL 与故障 DLL 不进入安装包。

安装器回归覆盖安装/修复/升级/回滚/卸载、文件校验、外来注册、占用 DLL、
词库/设置/学习文件保留和旧 ZIP 布局迁移。原生 MSVC CI 已配置，尚未远程执行。
只有 x64 DLL；ARM64、32 位应用、安全模式、实际 WinUI/UWP、RDP、管理员应用
仍待专门验收。核心零分配和 Linux 微基准不等同于 Windows 端到端延迟。

本版 87,540 条词库的 Linux 云机核心微基准：全拼逐键 P99 约 0.64 ms、
首拼混输约 2.60 ms、连续上下文约 5.41 ms；内存词库加载约 72 ms。
60 字节分隔显示 getter 的 P99 约 38 µs；4,096 项偏好成功上屏确认约 46 µs，
不含后台写盘。
尚未达到单键 0.5 ms/加载 50 ms 的项目目标，后续继续优化；完整口径见源码
`docs/PERFORMANCE.md`，实际 Windows 按键到候选呈现仍待测量。

构建机需要 Rust 1.82+、Visual Studio 2022 C++/Windows SDK、CMake 3.20+、
Python 3.11+、NSIS 3.11+；Developer PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\platforms\windows\Build.ps1
```

生成 `build/packages/chengyin-windows-x64-0.1.0-preview7-msvc.exe`。CTest 不改系统注册。
下列安装器测试会改变注册和文件，只用于干净的隔离 runner：

```powershell
python scripts/test_windows_installer.py --package build/packages/chengyin-windows-x64-0.1.0-preview7-msvc.exe --build-dir build/windows-msvc --makensis "C:\Program Files (x86)\NSIS\makensis.exe"
```

GNU 包需 GCC/MinGW 许可文件；NSIS 来源见 packaging/windows/README.md。
历史 PowerShell 安装脚本不包含在新 EXE 中。开发流程与配置发布细节见源码
`docs/DEVELOPMENT.md`；当前工作环境与验证边界见 `docs/ENVIRONMENT.md`。
