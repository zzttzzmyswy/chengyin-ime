# 候选皮肤

设置 → 主题，提供系统（自动亮暗）、白、黑、青瓷 · 雨后、夜航 · 星图、深蓝来信 · 鲸鱼娘。
鲸鱼娘为 Q 版二创插画。候选字大小仍在“候选”页配置；皮肤不缩小字体。
可关闭“显示皮肤装饰”进一步紧凑化；空间不足时自动隐藏装饰。
系统高对比度开启时采用系统可读配色并隐藏皮肤装饰。

## 自定义

- 导入 `.cyskin` 后点击应用。最多收藏 64 份，原始导入文件不被改写；可从列表移除收藏。
- 在设置页调整面板/文字/选中颜色、圆角、留白、装饰纹样或更换 PNG；修改先预览，应用时另存一份。
- “导出皮肤”生成包含图片的单个文件，方便分享和编辑；无需保持外部图片路径。
- PNG 宽高均不超过 1024 px，压缩文件不超过 2 MiB。推荐透明背景、512 px、清晰轮廓。
- 导入文件最大 3 MiB，UTF-8 无 BOM。文字、次要文字、纠错强调色对两种面板色，选中文字对选中色需达 4.5:1。
- 本格式参考搜狗皮肤的资源/排版分离方式，不兼容 `.ssf`，不执行脚本或下载外部资源。

## 文件格式 v1

每行 `Key=Value`，颜色 `#RRGGBB`，`#` 开头整行为注释，不允许重复/未知字段。
Version、Name 必填；其余省略时采用青瓷默认值。名字最多 48 个 UTF-16 单元。
保存器输出完整字段并把 Version/Name 放在文件头，以便收藏列表快速读取。

```ini
Version=1
Name=青瓷 · 我的皮肤
Background=#E5F1ED
Surface=#F8FCF8
Text=#1C3D36
Muted=#4B6B61
Border=#AECABC
Accent=#24705B
Selected=#246352
SelectedText=#FFFFF9
Radius=12
Padding=6
Ornament=1
```

颜色不含空格。Radius 为 0–24，Padding 为 3–12，单位为 96 DPI 逻辑像素。
Ornament 为 0 无纹样、1 枝叶、2 星图、3 波纹。可选 `Image=` 后为 PNG 的单行 Base64；
推荐通过设置页“更换插画”添加，然后导出，避免手工编码。

正常输入宿主通过原有配置通知及文件变更补偿接收新皮肤。资源在加载配置时读入不可变快照，按键/绘制不读文件。
受限 TSF 宿主仍用内存默认设置，不读取自定义文件；第三方宿主选择自己绘制候选时，外观由宿主管理。
物理混合 DPI 与完整实机矩阵需单独验收，不能用模拟 DPI 测试代替。

参考：[搜狗官方皮肤编辑器说明](https://pinyin.sogou.com/help.php?list=5&q=3)。
插画来源与生成提示词见 [assets/skins/README.md](../assets/skins/README.md)。
