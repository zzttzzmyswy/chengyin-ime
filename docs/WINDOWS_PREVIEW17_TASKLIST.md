# Windows preview17：完整声母缩写优先

用户要求：`ssdd` 明显是四个字的拼音头，匹配到的四字词语最前，真的找不到再考虑少字方案。
新开发分支 `codex/initials-word-priority`，基于已结项 preview8–16 的本地主干。

- [x] 复现全模糊音/纠错下 `ssdd` 首页为“舍得、杀得、舍得到、杀毒打、舍得多”。
- [x] 共享词库增加完整音节与字数校验的首字母索引；纯声母缩写一字一个首字母精确查询。
- [x] 存在完整词条时先走同字数词语，不被较少字、重复键或组合声母解释抢先；无完整词才回退。
- [x] 保留最多两项对应字数的准确历史提权；短字数历史不能干扰，词库切换使缓存失效。
- [x] 正常缩写不显示纠错标记；真正的错拼、全拼、前缀上屏与原始拼音提交保持兼容。
- [x] 73 项 Rust（新增 6 项）、137 同音词完整分页、分隔符、2/3/4/5/40 字、长规范拼音安全、编辑、学习及二进制加载通过。
- [x] fmt、Clippy -D warnings、初始化后零按键分配、64 KiB 上限、MSVC /W4 /WX C ABI 通过。
- [x] Windows 本机编译，7/7 CTest 25.91 s；生产词库原生候选窗口横/纵布局、ABI 选择上屏检查通过。
- [x] 核心微基准已记录硬件、87540 条语料、范围及百分位，见 [性能](PERFORMANCE.md)。
- [x] 最终单 EXE、7-Zip、解包完整 SHA-256/COM、三二进制与最终构建一致、21 项许可 ZIP CRC 检查。
