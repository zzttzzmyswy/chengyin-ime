## 匹配范围

| 设置 | 作用位置 / 示例 |
| --- | --- |
| zh↔z、ch↔c、sh↔s、n↔l、f↔h、l↔r | 音节开头；双向，只开启勾选的组 |
| an↔ang、en↔eng、in↔ing、ian↔iang、uan↔uang | 音节结尾；双向，只开启勾选的组 |
| 相邻交换 | zhnag → zh**an**g |
| 漏一个字母 | zhng → zh**a**ng |
| QWERTY 相邻键 | zhsng → zh**a**ng；使用键盘行与错位坐标，含相邻行 |
| 重复按键 | zhaang → zh**a**ng |

不做任意全排列或任意编辑距离搜索。键盘失误至少需要三个输入字母，每音节最多一次、每词最多两次。
模糊音只作用于声母开头或韵母结尾。trie 每次遍历最多 4096 个状态、候选根最多 256 个，耗尽显式报告限制。
输入结束后的普通补全不是输入错误，不标记未输入的后缀。显式撇号不会被当作交换/误按字母。

为满足辨认纠错位置的要求，纠错候选即使宿主支持内嵌编辑，也显示其标准拼音；
普通候选沿用内嵌可编辑时不重复显示拼音的规则。字母标记不改变选择/提交和原始输入。
