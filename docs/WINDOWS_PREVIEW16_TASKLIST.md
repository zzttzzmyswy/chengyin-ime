# preview16 从前到后分段上屏

2026-10-05。用户要求在整词/整句匹配之外，增加从开头取词组或单字；
选择一部分立即上屏，后续拼音重新匹配。

- [x] 保留 preview15 整词保护、搭配质量约束和独立的准确/模糊历史字词两线。
- [x] 追加独立的准确词库前缀流，只取剩余输入开头；按较长输入范围优先、同范围词库频序分页。
  不用合成组句凑前缀；每个音节不能仅因音节自身有较短词库开头就被切开。
- [x] 不再受解码 beam 的 64 项前缀缓存限制：每个有效结束点复用候选游标，前缀同音表惰性完整分页。
  仍沿用整个会话 4096 总候选预算；达到预算明确报告受限，不声称无限候选。
- [x] Windows 默认启用立即分段上屏；选择词组或单字只提交其文字，删除消耗的拼音，剩余输入重新查词。
- [x] 增加 C ABI v1 可选 configure_incremental(0/1)，默认旧分段预编辑协议；
  模式 1 可同时返回 COMMIT/PREEDIT，旧适配器和可撤销暂存段行为保持兼容。

  ShiftStart 会移除离开 composition 的文字的 GUID_PROP_COMPOSING 属性：
  [Microsoft 官方协议](https://learn.microsoft.com/en-us/windows/win32/api/msctf/nf-msctf-itfcomposition-shiftstart)。
- [x] 宿主已写入后范围/光标操作失败时吞掉原选择，避免再次输入；失败边界恢复有效光标再关闭编辑。
- [x] Home、退格、取消仅影响剩余输入；已上屏文字不会变回拼音。空格仍提交剩余原始拼音。
- [x] 学习键仅含已选前缀（去掉分段末尾分隔符），只在宿主接受文字及新范围后确认，确认后重新排序剩余候选。
