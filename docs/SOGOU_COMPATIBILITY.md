# 搜狗词库兼容

Windows 设置的“追加词库”支持 `.scel` 细胞词库和搜狗文本导出，并保留
已有词条；首次追加以 87,540 条内置词库为基础。“替换词库”只使用导入文件，
“恢复内置词库”移除本地快照。保存前完整校验，失败保留之前的文件。

| 格式 | 支持范围 |
| --- | --- |
| SCEL | `40 15 00 00`、0x44/0x45、`DCS\x01` 经典头；0x1540 拼音表，紧接词条或旧版零填充区；UTF-16LE；同音词组、稀疏拼音 ID、可变长度扩展及频率 |
| 搜狗文本 | `'ni'hao 你好`，可加正整数词频；UTF-8、UTF-8 BOM、UTF-16LE BOM；Windows 额外支持 GBK |
| 本项目 TSV | `ni'hao<TAB>你好<TAB>100`；导入时重复项取较大频率 |
| 本项目二进制 | 读取 v1/v2，保存为 v2；校验 UTF-8、节点关系、排序、范围和 CRC32 |

未知版本、加密词库、搜狗账号同步及其他 `.bin/.bak` 私有格式尚不支持。
规范拼音最长 255 字节，文字最长 256 UTF-8 字节，输入事件串仍最多 63 字节。
较长词条可用首拼。完整词库/追加结果最多 250,000 条、文件最多 64 MiB；
超过限制整体拒绝。零频率 SCEL 词条规范化为 1。

解析器在安全 Rust 核心实现，无平台 I/O。长度、拼音引用、重复 ID、UTF-16、
条目计数、词条语法和资源上限逐项检查；不忽略损坏记录或部分保存。Windows
用互斥锁串行化设置更新，再写唯一临时文件、FlushFileBuffers 和原子替换。
升级/卸载保留本地快照；重新激活输入法加载它，旧会话继续持有原快照。

自动化用本项目生成的 SCEL 测试两种头、固定/紧凑拼音区、稀疏 ID、同音组、
每一个截断位置、无效编码和版本，另测 Unicode/GBK、追加及失败保留。还实际
转换了公开格式参考仓库中的 157,720 字节经典 SCEL，得到 3,563 条词条，
最长规范拼音 105 字节；该样例只存于忽略的开发目录，不预载或再分发。
参考仓库：[imewlconverter](https://github.com/studyzy/imewlconverter)，修订
`a3cbd9727ce1c49039bab91a21052c1c8a282d50`；只参考字段格式和验证样例，
没有把其 GPL 实现纳入本项目。不能据一个样例宣布所有搜狗版本均兼容。

CLI 使用同一个解析器：`myswy --import 词库.scel 输出.mswydict`；CLI 的文本
输入使用 Unicode，GBK 文本需先转换为 UTF-8。搜狗词库由用户本地导入，
安装包只预载具有明确开源许可的 Rime/jieba 数据。
